# Komşu Tavanı Titreşim Mahkemesi

Bu yazılım, üst kattaki komşunun gece 02:17'de attığı terliği **uluslararası akustik hukuk** çerçevesinde yargılar.

Bilimseldir. Ciddidir. Aynı zamanda hiç ciddî değildir. Mahkeme mührü her iki durumu da onaylar.

## Ne Yapar?

1. Terlik düşme sesini Hertz cinsinden hayal eder.
2. Suçun ağırlığını "tek terlik" / "çift terlik" / "sandalye kaydı" skalasında puanlar.
3. Resmi kararname basar.
4. Temyiz hakkını teoride tanır, pratikte dinlemez.

## Kurulum

```bash
python3 mahkeme.py
```

Bağımlılık yoktur. Adalet kendi kendini taşır.

## Örnek Karar

```
KARAR NO: 2026/TAVAN-441
SANIK: Üst kat (kimliği muğlak)
SUÇ: Gece vakti terlikle tavanı ikna etmeye çalışmak
HÜKÜM: 3 gün sessiz çorap
```

## Katkı

PR açmadan önce kendi tavanınızı dinleyin. Kanıt yoksa hayal gücünüz yeter.
